## 配置与外部依赖

- 页面依赖 jQuery、Bootstrap、iziToast、Font Awesome、APlayer 及远程字体 CDN。
- 一言、天气、音乐、在线壁纸和 51.LA 使用外部服务；本轮没有调用这些服务。
- `main.js` 的高德 Key 与 `51LA.js` 的统计标识直接在前端中，查看网页即可看到。发布前确认它们属于当前项目，按服务要求配置适用范围；不要把服务端密钥放进静态页面。
- PWA 清单使用 `/manifest.json` 和 `/` 启动地址，旧浏览器跳转也从 `/` 开始；放在仓库子路径时可能跑到域名根目录。
- `sw.js` 从远程 CDN 加载 Workbox，缓存可能使本地更新后的 CSS/JS 延迟显示。
- 控制台仍显示版本 1.3.2.1 / 2026-02-04，旧说明写 1.1；它们不能作为当前目录的可靠版本记录。
